# Ratio: Transitions/Transversions (ti/tv)

- **ID:** ratio_transitions_transversions_snv
- **Description:** The ratio of transition SNV alternate alleles to transversion SNV alternate alleles observed in the [autosomal non-gap regions](terminologies.md#autosomes-non-gap-regions). Transitions are defined as A↔G and C↔T substitutions; transversions comprise all other single-nucleotide substitutions. Only biallelic [high-quality variants](terminologies.md#high-quality-variants) (`FILTER=PASS`) with an alternate genotype (`GT="alt"`) are included. Multiallelic records must be split, and variants must be atomized and normalized (reference-based left-aligned) prior to calculation. The same definition and evaluation regions apply across short-read, contiguous long-read, and discontiguous long-read callsets. Ti/Tv serves as a broad QC indicator of variant-calling behavior, with expected values depend on the target genomic regions and the sequencing assay.
- **Implementation details:** In the [NPM-sample-QC](References.md#npm-sample-qc) reference implementation, multiallelic records are split, and variants are atomized and normalized (reference-based left-aligned) against the matching reference FASTA using [bcftools](https://www.htslib.org/doc/bcftools.html) (`bcftools norm -m -any -f reference.fa`). The callset is restricted to autosomal non-gap intervals, retaining only passing (`FILTER=PASS`), biallelic SNVs with an alternate genotype (`GT="alt"`). Transitions (Ts) and transversions (Tv) are counted separately, and the transition-to-transversion ratio is calculated by dividing the transition count by the transversion count. When the transversion count is zero, N/A is reported rather than infinity. The same procedure is used for every sequencing read type.

#**Alternative method**
- **Implementation details:** In the [NPM-sample-QC](References.md#npm-sample-qc) reference implementation, multiallelic records are split, and variants are atomized and normalized (reference-based left-aligned) against the matching reference FASTA using [bcftools](https://www.htslib.org/doc/bcftools.html) (`bcftools stats`). The callset is restricted to passing (`FILTER=PASS`), biallelic SNVs with an alternate genotype (`GT="alt"`) across autosomal non-gap intervals. Transition counts, transversion counts, and their ratio (Ti/Tv) are then computed directly from the summary statistics generated by `bcftools stats`. If the transversion count is zero, N/A is reported. The same procedure is used for every sequencing read type.
- **Comments:**
```
# Normalize, atomize, split multiallelic records, and filter to passing autosomal biallelic SNVs for the sample
bcftools norm -m -any -f reference.fa input.vcf.gz \
  | bcftools view -R autosomal_nongap.bed -f PASS -v snps -m 2 -M 2 -i 'GT="alt"' > filtered_snvs.vcf

# Count Transitions (A<->G, C<->T)
n_ts=$(bcftools filter -i '(REF="A" && ALT="G") || (REF="G" && ALT="A") || (REF="C" && ALT="T") || (REF="T" && ALT="C")' filtered_snvs.vcf \
  | grep -v '^#' \
  | wc -l)

# Count Transversions (A<->C, A<->T, C<->G, G<->T)
n_tv=$(bcftools filter -i '(REF="A" && ALT="C") || (REF="A" && ALT="T") || (REF="C" && ALT="A") || (REF="C" && ALT="G") || (REF="G" && ALT="C") || (REF="G" && ALT="T") || (REF="T" && ALT="A") || (REF="T" && ALT="G")' filtered_snvs.vcf \
  | grep -v '^#' \
  | wc -l)

# Compute Ti/Tv ratio
awk -v ts="$n_ts" -v tv="$n_tv" 'BEGIN {
  if (tv > 0) printf "%.4f\n", ts / tv;
  else print "N/A"
}'
```
```
# Normalize, atomize, split multiallelic records, and filter to passing autosomal biallelic SNVs for the sample
bcftools norm -m -any -f reference.fa input.vcf.gz \
  | bcftools view -R autosomal_nongap.bed -f PASS -v snps -m 2 -M 2 -i 'GT="alt"' \
  | bcftools stats - \
  | grep '^TSTV' > tstv.txt

# Extract component counts and ratio:
# Columns: [1]=TSTV, [2]=id, [3]=ts, [4]=tv, [5]=ts/tv
n_ts=$(awk '{print $3}' tstv.txt)
n_tv=$(awk '{print $4}' tstv.txt)
titv_ratio=$(awk '{if ($4 > 0) print $5; else print "N/A"}' tstv.txt)

echo "Transitions: $n_ts"
echo "Transversions: $n_tv"
echo "Ti/Tv Ratio: $titv_ratio"
```
