# Yield in bases from reads at Q10/Q20/Q30
- **ID:** yield_bp_read_q10_q20_q30
- **Description:** Total yield in base pairs derived from eligible [high-quality reads](terminologies.md#high-quality-reads) whose read-level mean quality scores meet or exceed Q10, Q20, and Q30 thresholds across short-read, contiguous long-read, and discontiguous long-read datasets. For every qualifying primary record, the complete sequenced query sequence length (SEQ length, including soft-clipped bases but excluding hard-clipped bases) is added to the cumulative yield for that threshold. The eligible-read population comprises mapped and unmapped primary records, excluding secondary and supplementary alignments while retaining duplicate reads. For ONT, the platform-reported mean basecall Q-score (qs tag) is used. For PacBio HiFi, predicted read accuracy (rq tag) thresholds of $\ge 0.90$, $\ge 0.99$, and $\ge 0.999$ are applied, with an rq of 1.0 qualifying at all three thresholds. For paired-end short-read and discontiguous long-read data, base yields are accumulated per read end; unsequenced intervening template spans do not contribute to this metric.
- **Implementation details:** In the [NPM-sample-QC](References.md#npm-sample-qc) reference implementation, base yields stratified across quality thresholds (Q10, Q20, Q30) are evaluated on mapped and unmapped primary records within the declared input BAM/CRAM file. Alignments marked as secondary (0x100) and supplementary (0x800) are excluded using samtools (-F 2304), while duplicate reads (0x400) are retained. For contiguous long-read datasets, cumulative base yields can be parsed directly from the summary text matrix generated by (`NanoStat --no_supplementary`). For platform-specific long-read BAMs, base yields are tallied by summing the query length of records satisfying the `qs` (ONT) or `rq` (PacBio) cutoffs. For short-read data, the mean base quality per read is computed from the QUAL string and qualifying query sequence lengths are summed. If the total read count is zero, 0 is reported for each threshold. The same procedure applies to every sequencing read type.
- **Comments:** 
Record the input type, platform, basecaller or consensus-caller version and model, pass/fail inclusion rule, and any trimming or prior filtering. Alignment is not required.
```
# Option 1: Direct base yield extraction via NanoStat for long-read data (no plots generated)
NanoStat --bam input.bam \
  --no_supplementary \
  --threads 4 \
  > nanostats.txt

# Extract base yield passing quality thresholds from NanoStat summary table
q10_bases=$(awk -F':' '/Number of bases >Q10/ {gsub(/,/, "", $2); print $2}' nanostats.txt | tr -d ' ')
q20_bases=$(awk -F':' '/Number of bases >Q20/ {gsub(/,/, "", $2); print $2}' nanostats.txt | tr -d ' ')
q30_bases=$(awk -F':' '/Number of bases >Q30/ {gsub(/,/, "", $2); print $2}' nanostats.txt | tr -d ' ')

echo "Bases >= Q10: ${q10_bases:-0}"
echo "Bases >= Q20: ${q20_bases:-0}"
echo "Bases >= Q30: ${q30_bases:-0}"

# Option 2: Short-read base yield extraction via samtools and QUAL conversion
samtools view -F 2304 input.bam \
  | awk '
    BEGIN {
      for (i = 33; i <= 126; i++) ord[sprintf("%c", i)] = i - 33
    }
    {
      qual_str = $11
      seq_len = length($10)
      if (seq_len == 0 || qual_str == "*") next

      sum = 0
      for (i = 1; i <= seq_len; i++) {
        sum += ord[substr(qual_str, i, 1)]
      }
      mean_q = sum / seq_len
      if (mean_q >= 10) bp_q10 += seq_len
      if (mean_q >= 20) bp_q20 += seq_len
      if (mean_q >= 30) bp_q30 += seq_len
    }
    END {
      print "Bases >= Q10: " (bp_q10 ? bp_q10 : 0)
      print "Bases >= Q20: " (bp_q20 ? bp_q20 : 0)
      print "Bases >= Q30: " (bp_q30 ? bp_q30 : 0)
    }'

```
PacBio `rq` tag - compute both metrics reads count $\ge$ Q10, Q20, Q30 and base yield $\ge$ Q10, Q20, Q30
samtools view -F 2304 input_pacbio.bam \
  | awk '
    {
      seq_len = length($10)
      for (i = 12; i <= NF; i++) {
        if ($i ~ /^rq:f:/) {
          split($i, a, ":")
          rq = a[3] + 0.0
          if (rq >= 0.90) {
            q10_reads++
            q10_bases += seq_len
          }
          if (rq >= 0.99) {
            q20_reads++
            q20_bases += seq_len
          }
          if (rq >= 0.999) {
            q30_reads++
            q30_bases += seq_len
          }
          break
        }
      }
    }
    END {
      printf "Reads >= Q10: %d | Bases >= Q10: %d\n", q10_reads, q10_bases
      printf "Reads >= Q20: %d | Bases >= Q20: %d\n", q20_reads, q20_bases
      printf "Reads >= Q30: %d | Bases >= Q30: %d\n", q30_reads, q30_bases
    }'

  - [pysam](https://pysam.readthedocs.io/) aggregation of BAM read length and the ONT `qs` or PacBio HiFi `rq` tag, using the same thresholds and inclusion rules
