# Genome coverage uniformity

- **ID:** genome_coverage_uniformity
- **Description:** A sequencing-read-type-specific measure of how evenly usable sequencing depth is distributed across the defined autosomal non-gap evaluation regions of the selected reference genome. The same reference assembly and evaluation-region file must be used when comparing results. For short reads and discontiguous long reads, report the median absolute deviation (MAD) of per-base coverage derived from instrument-filter-passing reads where such a filter exists, non-duplicated primary alignments with mapping quality ≥20, and aligned bases with base quality ≥20. Exclude unmapped, secondary, supplementary, QC-failed, and duplicate alignments, and count overlapping paired-end bases only once. For discontiguous long reads, only the aligned bases of the paired sequence observations contribute to coverage; the inferred template span between them must not be counted as continuous sequence coverage. For contiguous long reads, divide the autosomal non-gap evaluation regions into non-overlapping, full-length 10,000-bp windows and calculate the mean depth in each window. Across the window mean depths, report Q1, median, Q3, interquartile range (IQR), and unscaled MAD. Include zero-coverage windows and exclude incomplete windows shorter than 10,000 bp. Include non-duplicated primary contiguous-long-read alignments with mapping quality ≥20 from reads passing a fixed, platform-appropriate minimum per-read quality threshold. Do not apply an individual-base-quality threshold. For ONT, use the basecaller-provided per-read `qs` value or its documented equivalent. For PacBio, use the `rq` predicted-accuracy value or its documented equivalent. The per-read quality threshold and quality-score definition must be reported.
- **Implementation details:** The reference implementation is sequencing-read-type-specific.
  - For short-read and discontiguous-long-read data, use the [NPM-sample-QC](References.md#npm-sample-qc) implementation based on [GATK Picard CollectWgsMetrics](terminologies.md#picard-collectwgsmetrics) and report the `MAD_COVERAGE` field. Restrict the calculation to the agreed autosomal non-gap intervals and use instrument-filter-passing reads where such a filter exists, non-duplicated primary alignments, minimum base quality 20, minimum mapping quality 20, and paired-end overlap removal. For discontiguous long reads, calculate depth only from aligned read bases and do not enable any fragment- or template-coverage mode.
  - For contiguous-long-read data, first select reads using the agreed technology-specific minimum per-read quality threshold and exclude unmapped, secondary, supplementary, QC-failed, and duplicate alignments. Partition each autosomal non-gap interval into consecutive, non-overlapping, full-length 10,000-bp windows. In the [mosdepth v0.3.14](https://github.com/brentp/mosdepth) implementation, run `mosdepth --no-per-base --by autosomal_non_gap_10kb.bed --mapq 20 --flag 3844 sample aligned.filtered.bam`. Calculate Q1, median, Q3, IQR (`Q3 - Q1`), and unscaled MAD (`median(abs(window_mean_depth - median_window_depth))`) from the window mean depths in `sample.regions.bed.gz`.
  - Record the tool versions, reference assembly, evaluation-region checksum, 10-kb-window checksum and treatment of partial windows for the contiguous-long-read profile, mapping-quality threshold, base- or per-read-quality profile, per-read quality threshold where applicable, aligner, and basecaller or consensus-caller version. Per-base MAD values for short-read and discontiguous-long-read data and 10-kb window summaries for contiguous-long-read data describe uniformity at different scales and must not be compared as numerically equivalent values.
- **Type:** Sequencing-read-type-specific: Float for short-read and discontiguous-long-read per-base MAD (eg. 4.00) | Structured numeric summary for contiguous-long-read data (eg. Q1: 27.40; median: 30.10; Q3: 32.60; IQR: 5.20; MAD: 2.10)
- **Functionally equivalent implementations:**
  - [ICGC-ARGO dnaalnqc](References.md#icgc-argo) for the short-read or discontiguous-long-read profile when it reproduces the reference implementation's intervals and filtering.
  - [samtools depth](https://www.htslib.org/doc/samtools-depth.html), followed by an exact per-base MAD calculation that includes zero-coverage positions, for short-read or discontiguous-long-read data when the same evaluation intervals, base-quality threshold, mapping-quality threshold, duplicate policy, primary-alignment policy, and overlap policy are used.
  - [samtools depth](https://www.htslib.org/doc/samtools-depth.html) followed by the identical 10-kb aggregation for the contiguous-long-read profile after the same per-read quality and alignment filtering.
  - [bedtools genomecov](https://bedtools.readthedocs.io/en/latest/content/tools/genomecov.html) followed by the identical 10-kb aggregation, after reproducing the applicable sequencing-read-type-specific filtering and overlap policy.
- **Sequencing read type:** short-read | contiguous-long-read | discontiguous-long-read
- **Reference genome assembly:** GRCh37 | GRCh38
- **Version:** 2.0
- **Sequencing technology:** Illumina | Oxford Nanopore Technologies (ONT) | Pacific Biosciences (PacBio) | Illumina TruPath Genome (proximity mapped reads; formerly Constellation)
- **Associated aligner:** BWA-MEM/BWA-MEM2 or DRAGEN mapper (Illumina short-read) | minimap2 (ONT) | pbmm2/minimap2 (PacBio) | DRAGEN TruPath pipeline (Illumina proximity mapped reads). Record the exact version and parameters.
- **Associated basecaller:** N/A (Illumina short-read and proximity mapped reads) | Dorado (ONT) | SMRT Link/CCS (PacBio). Record the exact version and model where applicable.
