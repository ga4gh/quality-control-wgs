# Percent autosomes with ≥N-fold coverage

- **ID:** pct_autosomes_n_fold_coverage
- **Description:** The percentages of bases in the defined autosomal non-gap evaluation regions of the selected reference genome attaining sequencing depth ≥5×, ≥10×, and ≥15× after applying sequencing-read-type-specific inclusion criteria. All three thresholds must be reported. The same reference assembly and non-overlapping evaluation-region file must be used when comparing results. For short reads, include instrument-filter-passing reads where such a filter exists, non-duplicated primary alignments with mapping quality ≥20, and aligned bases with base quality ≥20. Exclude unmapped, secondary, supplementary, QC-failed, and duplicate alignments, and count overlapping paired-end bases only once. For discontiguous long reads, apply the same inclusion criteria as for short-read data because the sequence observations are paired short reads supplemented with long-range proximity information; the inferred template span must not be counted as continuous sequence coverage. For contiguous long reads, include non-duplicated primary alignments with mapping quality ≥20 from reads passing a fixed, platform-appropriate minimum per-read quality threshold. Do not apply an individual-base-quality threshold. For ONT, use the Dorado or MinKNOW `qs` tag, which contains the per-read mean basecall Q-score, or its documented equivalent. For PacBio, use the `rq` tag, which contains predicted read accuracy, or its documented equivalent. Include all evaluated positions, including positions with zero coverage, in the denominator.
- **Implementation details:** The reference implementation is sequencing-read-type-specific.
  - For short-read and discontiguous-long-read data, use the [NPM-sample-QC](References.md#npm-sample-qc) implementation based on [GATK Picard CollectWgsMetrics](terminologies.md#picard-collectwgsmetrics) and report the `PCT_5X`, `PCT_10X`, and `PCT_15X` fields, each multiplied by 100 to express the result as a percentage. Restrict the calculation to the agreed autosomal non-gap intervals and use instrument-filter-passing reads where such a filter exists, non-duplicated primary alignments, minimum base quality 20, minimum mapping quality 20, and paired-end overlap removal. For discontiguous long reads, calculate depth only from aligned read bases and do not enable any fragment- or template-coverage mode.
  - For contiguous-long-read data, first select reads using the agreed technology-specific minimum per-read quality threshold and exclude unmapped, secondary, supplementary, QC-failed, and duplicate alignments. In the [mosdepth v0.3.14](https://github.com/brentp/mosdepth) reference implementation, run `mosdepth --no-per-base --by autosomal_non_gap.bed --thresholds 5,10,15 --mapq 20 --flag 3844 sample aligned.filtered.bam`. For each threshold, sum the corresponding counts from `sample.thresholds.bed.gz`, divide by the total non-overlapping length of `autosomal_non_gap.bed`, and multiply by 100. Positions with zero coverage remain in the denominator.
  - Report the three results using unambiguous threshold labels, for example `pct_5x`, `pct_10x`, and `pct_15x`. Record the Picard or mosdepth version, reference assembly, evaluation-region checksum, mapping-quality threshold, base- or per-read-quality profile, ONT `qs` or PacBio `rq` threshold where applicable, duplicate policy, overlap policy, aligner, and basecaller or consensus-caller version.
- **Type:** Structured float percentages, 2 decimal precision (eg. pct_5x: 99.10; pct_10x: 98.20; pct_15x: 96.02)
- **Functionally equivalent implementations:**
  - [ICGC-ARGO dnaalnqc](References.md#icgc-argo) for short-read or discontiguous-long-read data when it reproduces the reference implementation's evaluation regions, filtering, and all three depth thresholds.
  - [samtools depth](https://www.htslib.org/doc/samtools-depth.html), followed by counting evaluated positions with depth ≥5, ≥10, and ≥15 and division by the total evaluation-region length, when the same sequencing-read-type-specific filters, overlap policy, and zero-coverage denominator are used.
- **Sequencing read type:** short-read | contiguous-long-read | discontiguous-long-read
- **Reference genome assembly:** GRCh37 | GRCh38
- **Version:** 2.0
- **Sequencing technology:** Illumina | Oxford Nanopore Technologies (ONT) | Pacific Biosciences (PacBio) | Illumina TruPath Genome (proximity mapped reads; formerly Constellation)
- **Associated aligner:** BWA-MEM/BWA-MEM2 or DRAGEN mapper (Illumina short-read) | minimap2 (ONT) | pbmm2/minimap2 (PacBio) | DRAGEN TruPath pipeline (Illumina proximity mapped reads). Record the exact version and parameters.
- **Associated variant caller:** N/A
- **Associated basecaller:** N/A (Illumina short-read and proximity mapped reads) | Dorado/MinKNOW integrated Dorado (ONT) | SMRT Link/CCS (PacBio). Record the exact version and model where applicable.
